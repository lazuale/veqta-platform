# Приёмка PostgreSQL Cold Start

18 ноября 2026, Europe/Moscow. Итоговая проверка относится к коду 446691b1eca54af2833be61adbe23661f45f78eb. Полный итоговый SHA и коммиты — в manifest архива приёмки; сводный результат — [release_candidate_report.md](release_candidate_report.md).

Workwear содержит единственную 0001_initial. Миграция, модели и сервисы при этом аудите не менялись. Схема предназначена для пустой базы; к прежним DEV/PROD её не применяют. Перенос данных и --fake не используются.

Публичная HTTPS-сеть, запуск systemd на целевом сервере, отказоустойчивость и рабочий объём данных требуют отдельной серверной приёмки.
