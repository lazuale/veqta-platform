# Работа с заявками на спецодежду

Откройте модуль «Заявки на спецодежду» в Portal или перейдите на `/workwear/`. В реестре можно найти заявку по организации, состоянию, дате или сотруднику. Заявки видны по всем организациям при наличии разрешения просмотра.

## Доступ

Пользователей, группы и разрешения назначает администратор в `/admin/`. Разрешения принадлежат приложению `workwear`. Для аналитика, который готовит заявки, объедините просмотр, подбор и редактирование.

| Действие | Разрешение |
|---|---|
| Просмотр заявок всех организаций | `view_request` |
| Подбор сотрудников | `view_employee` |
| Просмотр текущего каталога | `view_workwearitem` |
| Просмотр журнала и предыдущих назначений | `view_request` и `view_workwearevent` |
| Создание и редактирование | `add_request` и `change_request` |
| Удаление черновика | `delete_request` |
| Возврат завершённой заявки | `reopen_request` |

## Подготовка заявки

1. Создайте черновик и выберите организацию. В списке создания отображаются организации, которым администратор разрешил новые заявки. Выбранная организация фиксируется при создании. [Управление справочниками](directories.md).
2. Подберите сотрудников по ФИО или табельному номеру. Для массового подбора вставьте один столбец, по одному значению на строку. При нескольких совпадениях выберите нужного сотрудника. Новое включение доступно для сотрудников организации заявки из последней принятой выгрузки. Ранее сохранённый состав остаётся доступен по снимкам.
3. Назначьте СИЗ в списке, матрице или карточке сотрудника. Для массового действия выделите сотрудников и позиции. Лимит заявки — 1000 сотрудников, у каждого до 30 позиций. Каталог может содержать больше позиций.
4. Сохраните изменения. При конфликте версии откройте актуальную заявку и сверяйте её с черновиком перед повторной попыткой. Запись с устаревшей версией отклоняется целиком.

В матрице до 100 строк и 30 колонок на странице. Флажок в заголовке относится к показанным строкам. Выделение сохраняется при переходе между страницами и действует на весь выбранный набор. Стрелки перемещают фокус, Home/End ведут к краю строки, Ctrl+Home/End — к краю состава, PageUp/PageDown переключают страницу сотрудников. Enter и пробел меняют назначение. На узком экране таблица прокручивается горизонтально.

Графа матрицы отражает текущий каталог. Подсказка назначенной ячейки, список и карточка используют название, категорию и срок из снимка этого назначения. У двух сотрудников могут быть разные снимки одной позиции, если каталог менялся между сохранениями. С отключённой позицией можно завершить заявку, если назначение уже сохранено.

## Завершение и история

При завершении интерфейс показывает, сколько сотрудников без позиций будет исключено. Если после их исключения состав окажется пустым, заявка останется черновиком со своим составом. Завершение фиксирует автора и дату и блокирует изменения. Пользователь с правом возврата может вернуть заявку в черновик. Причину можно указать при возврате.

Кнопка «История операций» открывает журнал заявки. Последними сверху идут сохранения состава, завершения и возвраты с авторами, временем и подробностями операций. Записи выдаются по 25 на страницу. История назначений отдельного сотрудника доступна из его карточки.

Предупреждение о повторе показывает остаток срока последнего подходящего назначения сотрудника на ту же позицию. Срок берётся из сохранённого назначения, отсчёт идёт с календарной даты завершения по московскому времени. В день истечения срока предупреждение исчезает. Заявку с предупреждением можно завершить.
