# Организации и каталог СИЗ

После установки справочники пусты. Войдите в `/admin/` под активной учётной записью с правами персонала и назначьте доступ к моделям через штатные группы Django.

| Модель | Разрешения |
|---|---|
| Организация | `view_organization`, `add_organization`, `change_organization`, `delete_organization` |
| Позиция спецодежды | `view_workwearitem`, `add_workwearitem`, `change_workwearitem`, `delete_workwearitem` |

Аналитикам назначайте права по их задачам. Ведение справочников требует отдельных разрешений. [Права на работу с заявками](workwear.md#доступ).

## Организация

1. В разделе Workwear откройте «Организации» и добавьте запись с отображаемым названием.
2. Укажите `orgExtId` из 1С в поле «Идентификатор 1С» перед приёмом сотрудников. Заполненный ID становится неизменяемым.
3. Включите «Разрешено создавать заявки», когда организация готова к работе.

Можно сначала [принять выгрузку 1С](import-1c.md). Для нового `orgExtId` появится запись с выключенным разрешением новых заявок. В Admin проверьте последнее название из 1С и включите заявки. Отключение организации запрещает создавать для неё новые заявки. Существующие остаются в реестре, с черновиками можно продолжить работу. Переименование меняет название для будущих заявок и включений сотрудников.

## Позиция СИЗ

В разделе «Позиции спецодежды» добавьте уникальный код, название и категорию. Код фиксируется при создании. Категория — текст, одинаковые названия группируют соседние позиции. Срок задаётся целым числом от 1 до 32767 календарных дней. Порядок отображения идёт от меньшего числа к большему. Включите признак «Активна», чтобы позиция была доступна для новых назначений.

После изменения имени, категории или срока новые назначения используют текущие данные. Сохранённые назначения читаются из своих снимков. Чтобы вывести позицию из использования, снимите «Активна». Отключённая позиция остаётся в истории и существующем составе. Удалить организацию или позицию, на которую ссылаются данные, запрещает PostgreSQL.

## Первоначальное заполнение каталога из CSV

Подготовьте файл в UTF-8 с разделителем `;`. Допускается BOM. Заголовок содержит ровно шесть полей:

```text
code;name;category;validity_days;sort_order;is_active
```

Поля `code`, `name` и `category` обязательны, максимальные длины 32, 120 и 64 символа. `sort_order` — целое от 0. `is_active` — `0` или `1`. Один код встречается один раз.

В окружении выбранного контура под прикладной ролью выполните сначала проверку, затем запись. Пример для DEV:

```bash
read -r -p 'Подтверждённое число позиций: ' CATALOG_COUNT
python manage.py workwear_load_catalog private/catalog.csv --environment dev \
  --database-name veqta_dev --expected-count "$CATALOG_COUNT"
python manage.py workwear_load_catalog private/catalog.csv --environment dev \
  --database-name veqta_dev --expected-count "$CATALOG_COUNT" --apply
```

Команда сверяет число строк и добавляет недостающие позиции одной транзакцией. Совпадающие записи сохраняются, конфликтующий код останавливает загрузку. Для дальнейших изменений используйте Admin.
